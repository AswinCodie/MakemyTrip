# ✈️ MakeMyTrip Clone

A simple front-end clone of the MakeMyTrip website built using **HTML5** and **Tailwind CSS**.

## 🚀 Features

- 📱 Responsive Design
- 🎨 Modern UI
- ✈️ Flight Booking Section
- 🏨 Hotel Booking Section
- 🚌 Bus Booking Section
- 🚆 Train Booking Section
- ⚡ Built with Tailwind CSS

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 Tailwind CSS
